# Búsqueda regional

`busqueda-regional-v1.json` fija el dominio del experimento: áreas terrestres, centros de control, productos GMTED, identidades locales, tamaño de ventana, escala de agregación, separación de centros, cobertura mínima y perfiles de filtro.

Los umbrales son exploratorios y no se calibraron con un conjunto de análogos verdaderos. El control Silver Lake procede de la ficha de viabilidad de fase 1; los otros controles conservan los centros de fase 2 y usan una ventana nueva. Las referencias y límites están en la [ficha de fase 4](../../docs/Fase%204%20-%20busqueda%20regional%20terrestre.md).

Cambiar la configuración exige regenerar y revisar la evidencia. No modificar los hashes esperados de un original para ocultar una descarga diferente. La auditoría conserva la conciliación del manifiesto de adquisición y comprueba todos los miembros de los ZIP.

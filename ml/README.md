# Aprendizaje automático

El motor de similitud ML no supervisado vive en [`pipelines/similarity_ml.py`](../pipelines/similarity_ml.py). Usa métricas aprendidas por vista, un GMM de regímenes morfológicos, fusión multivista con pesos por consulta y calibración Bradley-Terry por pares.

Ver [Motor de similitud ML no supervisado](../docs/01-vigentes/etapa-actual-armonizacion/Motor%20de%20similitud%20ML%20no%20supervisado.md). No hay modelos supervisados: faltan etiquetas independientes, según el análisis de viabilidad.

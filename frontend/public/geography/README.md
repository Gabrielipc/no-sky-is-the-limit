# Límites de países

`countries.json` contiene los nombres en español y geometrías de Natural Earth
Admin 0 – Countries, escala 1:110m. Se eliminaron las demás propiedades del
[GeoJSON original](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson).
Natural Earth publica estos datos en el [dominio público](https://www.naturalearthdata.com/about/terms-of-use/).
Los límites están generalizados: pueden omitir islas pequeñas o diferir de la
ubicación exacta cerca de fronteras y costas.

# Experimento de representación aprendida

Estado: **bloqueado por falta de parches topográficos reales y casos de revisión**. El catálogo distribuido contiene perfiles sintéticos agregados, no parches. Entrenar o evaluar una representación espacial con ellos produciría resultados sin significado científico; tampoco existe una separación geográfica entre desarrollo y revisión.

Cuando haya datos preparados, conservar identificadores y procedencia, separar regiones de desarrollo y revisión antes de ajustar el modelo, aprender una representación solo con desarrollo y recuperar candidatos del mismo conjunto usado por el motor físico. Registrar coincidencias, diferencias, ejemplos inesperados y evaluación humana; si la muestra sigue siendo pequeña, informar solo resultados cualitativos. Mantener el método experimental fuera de la búsqueda principal.
